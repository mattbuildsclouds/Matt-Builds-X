# Shortify

This repository contains the code for **Shortify** (also known as shortify.ai), an application for quickly generating concise summaries from longer text.

## Purpose

Shortify's goal is to make it easy to condense articles, notes, or any lengthy writing into short, digestible snippets.

## Getting Started

For now, the project includes a simple placeholder app. Run it with Python to see a basic message:

```bash
python app.py
```

You should see the word `Shortify` printed to the console. Further functionality will be added in future updates.
